# Vision Tools

当前目录包含以下 vision tools：

- `adjust_brightness`：调整图像亮度和对比度，用于提亮、压暗或增强整体可见性。
- `connected_components`：在阈值化图像中提取前景连通域，并返回边界框、中心点和面积。
- `crop`：裁剪图像中的指定矩形区域。
- `detect_edges`：使用 Sobel 算子生成边缘图，突出物体轮廓、文字边界和结构线条。
- `draw_bbox`：在图像上绘制一个或多个矩形边界框，可附带标签。
- `draw_circle`：在图像上绘制一个或多个圆形，可用于标记圆形目标或点位。
- `draw_line`：在图像上绘制一条或多条线段，可用于标注轴线、分割线或参考线。
- `enhance_contrast`：默认在 LAB 亮度通道上使用 CLAHE 增强图像对比度，同时尽量保留原始颜色。
- `find_contours`：提取阈值化图像中的轮廓，并返回面积、周长、边界框等形状信息。
- `flip`：按水平或垂直方向翻转图像。
- `grayscale`：将图像转为灰度图，或进一步二值化以分离前景和背景。
- `hough_circles`：使用霍夫变换检测圆形目标，适合识别气泡图、单选按钮或圆形标记。
- `hough_lines`：使用概率霍夫变换检测直线段，适合识别表格线、坐标轴和界面分隔线。
- `in_range_color`：按 HSV 或 BGR 颜色范围生成掩码，并返回匹配区域信息。
- `rotate`：按指定角度逆时针旋转图像，并自动扩展画布填充背景。
- `template_match`：在图像中查找与模板图或模板裁剪区域相似的位置。
